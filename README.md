# Sistema-de-Vendas

Este repositório contém um Sistema de Vendas feito com a linguagem de programação Java, desenvolvido na cadeira de Programação Orientada a Objetos (POO) com o auxílio do professor Igor Barbosa.  
Para tanto, para cada aula ministrada, uma nova versão do projeto era criada e neste repositório é possível ver o registro da evolução, tanto do projeto, quanto do meu aprendizado nessa cadeira.
